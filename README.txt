SHWETA — PERSONAL PORTFOLIO

Pages
- index.html: Minimal homepage with introduction and academic highlights (no photograph).
- resume.html: Resume page.
- biodata.html: Detailed profile, education, technical skills, project, certifications, interests and languages.

Files
- style.css: Shared responsive styling for all pages.
- script.js: Navigation and small interactive effects.
- resume.pdf: Resume download.
- certificates/foundation.pdf and certificates/advanced.pdf: Certificate PDFs.

Preview locally
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server, or open index.html directly in a browser.
4. Use the navigation to open Resume and Bio-data.

Publish
This is a static HTML/CSS/JavaScript/jQuery website and can be hosted on GitHub Pages.
Keep the folder structure unchanged so the PDF links continue to work.
