SHWETA — MODERN MINIMALIST PORTFOLIO

Files:
- index.html       Home page
- resume.html      Resume page
- biodata.html     Bio-data page
- style.css        Shared styling (white + royal blue theme)
- script.js        JavaScript + jQuery interactions
- resume.pdf       Your supplied resume
- certificates/    Your supplied certificates

HOW TO RUN:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with the Live Server extension, or double-click index.html.
4. Use the navigation to visit Home, Resume and Bio-data.

NOTES:
- jQuery is loaded from the official jQuery CDN, so internet access is needed for its interactions.
- Check all personal details and update anything that has changed before submission.
- Bio-data intentionally does not include date of birth, full residential address or phone number because those details were not needed for the public version.
- Do not publish sensitive personal details publicly.
- The education details and scores are reproduced from the supplied resume content; please verify them before final submission.
- The website is static and suitable for GitHub Pages hosting.
