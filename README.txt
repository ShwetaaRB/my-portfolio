Shweta Portfolio - how to use
1. Unzip the folder and double-click index.html (opens in any browser).
2. Pages: index.html (Home), resume.html, biodata.html. Contact links to the footer on each page.
3. style.css = all styling, script.js = jQuery behaviour. Replace resume.pdf / certificates/*.pdf / assets/shweta-photo.jpg to update.
4. jQuery and Google Fonts load from the internet; without a connection the site still works with fallback fonts, but the menu toggle and fade-in need jQuery.
